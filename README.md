# Информационная система агентства недвижимости «Ключ»

Курсовой проект по МДК.01.01 «Разработка программных модулей». Автор: С.А. Жариков, группа 320.

Настольное приложение для учёта объектов недвижимости, заявок клиентов и показов. Рассчитывает комиссию агентства (скидка 25 %, если в прошлом месяце заявок по объекту не было), контролирует остаток согласованных показов, ведёт заявки до завершения сделки и формирует отчёт по менеджерам.

## Технологии

C# (.NET 10), Avalonia UI 12.1.3, Entity Framework Core 10.0.12 (Database First), SQL Server 2025, Git и GitHub.

## Роли

Гость, клиент, менеджер, администратор. Тестовые учётные записи (пароль у всех `123`): `admin`, `manager_petrova`, `manager_sokolov`, `client_ivanov`.

## Запуск

1. В SSMS создайте базу `estate_agency` с параметрами сортировки `Cyrillic_General_CI_AS`.
2. Выполните скрипт `database/database_script.sql`.
3. Укажите свой сервер в `src/EstateAgency/connection.txt`.
4. Откройте `src/EstateAgency/EstateAgency.csproj` в Visual Studio и нажмите Ctrl+F5 либо выполните `dotnet run` в папке проекта.

## Папки

- `src/EstateAgency` — приложение: `Models`, `Data`, `Services`, `Views`, `Assets`.
- `database` — скрипт структуры и данных.
- `docs` — пояснительная записка и презентация.
- `resources` — сведения об изображениях.
